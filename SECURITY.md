# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting Issues

### Security Vulnerabilities

Report security vulnerabilities to **dev@kamilszpak.com**. Include:

1. Description
2. Reproduction steps
3. Affected version
4. Potential impact
5. Fix suggestions (optional)

I request a 90-day disclosure deadline. I will acknowledge reports within 48 hours.

### Bugs & Issues

Report logic errors or layout problems via [GitHub Issues](https://github.com/SzpakKamil/ColorKit/issues).

1. Include code/samples.
2. Note platform/version.
3. List reproduction steps.

### Feature Suggestions

Propose features via GitHub Issues ("enhancement" label). Describe the functionality and use case.

## Best Practices

1. **Update**: Use the latest version.
2. **Sanitize**: Validate user-provided hex strings.
3. **Headroom**: Monitor HDR values in sensitive UI.

## Commitment

I commit to:

- Addressing security concerns promptly.
- Fixing bugs timely.
- Considering all proposals.
- Maintaining transparency.

## Updates

Updates appear as new package versions with release notes.
